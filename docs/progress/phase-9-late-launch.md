## 발견
- 기록상 "미실행" 20개 중 **14개가 실제로는 43~422초에 실행**됨. Run 키 항목이 약 30초 간격으로 차례로 실행(153·183·213·274·304·334·365·418초). 원인(Windows 동작 방식)은 미확인, 관찰된 패턴만 사용
- 45초 미실행 규칙 때문에 71.5초에 땡! 선언 후 기록 종료 → 이후 실행은 기록에 없음
- 같은 기록이 3회 쌓이면 R3("등록만 남은 항목")가 14개에 잘못 나올 상황
- CrossEXService(43초 실행)를 sysinfo가 `exe=None, start=0, uid=None`으로 읽음(권한 상승·보호 프로세스로 추정) → 경로 매칭 실패, 시작 시각 0이라 거슬러 찾기 범위 밖
